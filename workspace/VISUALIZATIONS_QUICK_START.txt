 CHART TYPES EXPLAINED
───────────────────────────────────────────────────────────────

1. EMOTION DISTRIBUTION (Pie Chart)
   Shows: Overall breakdown of emotions detected
   Updates: After each message
   Use: Understand your dominant emotional states
   
2. EMOTION TIMELINE (Line Graph)
   Shows: How emotions change over time
   Updates: After each user message
   Use: Track emotional patterns and triggers
   
3. CONFIDENCE TREND (Line Graph)
   Shows: Model confidence in emotion detection
   Updates: After each detection
   Use: Assess model reliability
   
4. CONVERSATION STATS (Dashboard)
   Shows: Comprehensive session metrics
   Updates: On command (/stats)
   Use: Get overview of the session

 CUSTOMIZATION
───────────────────────────────────────────────────────────────

Want different colors or styles?

Edit: src/visualization_manager.py

Change emotion colors:
  self.emotion_colors = {
      'anger': '#YOUR_COLOR',
      ...
  }

Change chart height:
  fig.update_layout(height=600)

Apply dark theme:
  fig.update_layout(template="plotly_dark")


 PRIVACY & DATA
───────────────────────────────────────────────────────────────

 All data stored locally
 No cloud analytics
 Export is optional
 Delete anytime

Data locations:
  - In-memory: Active session only
  - logs/: Debug logs (optional)
  - Exports: Only if you use /export

To clear all data:
  Remove-Item -Recurse logs/
  Remove-Item conversation_export_*.json

 TROUBLESHOOTING
───────────────────────────────────────────────────────────────

Charts not showing?
  → Refresh the page
  → Check: pip install plotly
  → Verify data exists (try /stats)

Export fails?
  → Check disk space
  → Verify write permissions
  → Check logs/chatbot_chainlit_enhanced.log

Slow performance?
  → Export and start fresh session
  → Use standard interface (less features)
